# 📥 SaveMate TikTok Downloader Bot

Современный и быстрый Telegram-бот на **Python** и **aiogram 3** для скачивания видео и фото-публикаций (слайдшоу/каруселей) из **TikTok** в максимальном качестве без водяных знаков.

---

## 🚀 Возможности

- 🎬 **Скачивание видео без вотермарок**: загрузка в лучшем доступном качестве (HD без водяных знаков TikTok).
- 🖼 **Скачивание фото-публикаций**: полная поддержка постов-каруселей из картинок. Бот скачивает все фотографии и отправляет их аккуратным альбомом (`MediaGroup`).
- 🎵 **Аудиодорожки**: автоматическое извлечение и отправка оригинального звука / музыки из публикации.
- 💬 **Удобный интерфейс**:
  - Приветствие по команде `/start`.
  - Подробная справка по команде `/help`.
  - Автоматическое распознавание ссылок TikTok в тексте сообщения.
  - Живые индикаторы загрузки («печатает...», «загружает видео...») и статусные сообщения.
- ⚡️ **Асинхронность**: построен на базе `aiogram 3.x` и `aiohttp` для максимальной скорости и одновременной обработки запросов.
- 🐳 **Готов к развертыванию**: включает `Dockerfile` и `docker-compose.yml`.

---

## 📋 Форматы ссылок

Бот поддерживает все виды ссылок TikTok:
- `https://www.tiktok.com/@username/video/1234567890123456789`
- `https://www.tiktok.com/@username/photo/1234567890123456789`
- `https://vm.tiktok.com/ZMxxxxxx/`
- `https://vt.tiktok.com/ZSxxxxxx/`
- Ссылки, отправленные прямо в тексте сообщения с другим текстом.

## 🛠 Установка и запуск

### 1. Получение токена бота
1. Откройте Telegram и перейдите к [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям для создания бота.
3. Скопируйте полученный **API токен**.

---

### Вариант A: Локальный запуск (Python 3.10+)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/mercurialzxq/savemate_bot.git
   cd savemate_bot
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # Для Linux/macOS
   # или:
   # venv\Scripts\activate   # Для Windows
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения:**
   ```bash
   cp .env.example .env
   ```
   Откройте файл `.env` в любом текстовом редакторе и вставьте ваш токен:
   ```env
   BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz_EXAMPLE
   DOWNLOAD_TIMEOUT=60
   MAX_FILE_SIZE_MB=50
   ```

5. **Запустите бота:**
   ```bash
   python main.py
   ```

---

### Вариант B: Запуск через Docker / Docker Compose

1. **Настройте файл `.env`:**
   ```bash
   cp .env.example .env
   # Укажите ваш BOT_TOKEN в .env
   ```

2. **Запустите контейнер:**
   ```bash
   docker compose up -d --build
   ```

3. **Просмотр логов:**
   ```bash
   docker compose logs -f
   ```

4. **Остановка бота:**
   ```bash
   docker compose down
   ```

## ⚙️ Переменные конфигурации (.env)

| Переменная | Описание | По умолчанию |
| :--- | :--- | :--- |
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather | *Обязательно* |
| `DOWNLOAD_TIMEOUT` | Таймаут ожидания скачивания в секундах | `60` |
| `MAX_FILE_SIZE_MB` | Максимальный размер файла для отправки в Telegram (МБ) | `50` |
| `TEMP_DIR` | Папка для временных файлов | `./tmp` |
